# 鱼泡网求职招聘招工招聘灵活用工小程序app企业求职boss招聘人力资源小程序

源码地址：ym7k.com/19207/

专为建筑行业打造的蓝领招工找活小程序，对标鱼泡网业务模式，主打工地用工、包工头招工、技工找活，适合建筑劳务、工程班组、本地劳务公司搭建工程用工平台，独立私有化部署。

### ✅ 工人端核心功能

- **找活名片**：工人专属电子名片，填写工种、工龄、工作地点、自我介绍，上传项目经验（项目时间、地点、现场图片），展示职业技能，打造个人技工简历
- **浏览招工详情**：查看工地招工岗位，项目描述、联系方式，支持收藏、分享、投诉岗位
- **双向匹配**：工人主动浏览招工，包工头定向筛选合适技工
- **会员中心**：积分充值、积分记录、邀请工友、实名认证、实名查询、消息通知
- **数据看板**：我的找活、谁看过我，随时查看曝光与访客记录

### ✅ 招工方（包工头 / 老板）功能

- **快速招工**：一键发布工地招工，填写工种、工作地点、项目详情，附带联系方式
- **查看工人名片**：查看技工工龄、擅长工种、过往施工项目经验，精准挑选班组工人
- **访客记录**：查看哪些工人浏览过自己发布的招工信息
- **收藏、点赞、转发工人名片，方便后续联系班组**

### ✅ 平台盈利与基础机制

- 积分体系：充值积分用于查看号码、岗位置顶、曝光增值
- 实名认证：降低虚假招工、虚假工人信息，提升平台可信度
- 邀请工友分销，裂变拉新
- 消息推送：招工更新、意向工人通知
- 投诉举报入口，管控违规信息

### ✅ 适用工种场景

钢筋工、铁工、外墙保温、吊绳、泥工、抹灰、钢砖、贴砖、木工、铝模、模板等各类建筑技工，也可拓展普工、短期临时工。

### ✅ 核心亮点

✅ 特色项目经验模块：工人可以上传过往工程案例 + 配图，包工头直观判断手艺
✅ 独立工人名片，可点赞、收藏、分享，方便班组传播
✅ 工地场景深度适配，建筑工种自定义分类
✅ 双向业务：老板招工、工人主动自荐找活
✅ 积分变现、邀请分销、实名认证一套闭环
✅ 小程序端，无需下载 APP，工人打开即用

### ✅ 适合落地

建筑劳务公司、工程包工头、工地招工平台、县域工程蓝领用工、建筑班组接单平台
